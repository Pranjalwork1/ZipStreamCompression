How ZipStream P2P PDF Co-Viewer Works

ZipStream's P2P Co-Viewer uses encrypted WebRTC data channels to stream PDF documents directly between browsers — no server storage, no upload delay. The host selects a PDF locally; it gets chunked into 32 KB binary buffers and transmitted peer-to-peer over DTLS-encrypted channels. Peers receive the file and render it simultaneously in a synchronized view.

Key Features

  • Zero-install — runs entirely in any modern browser
  • End-to-end encrypted WebRTC data channels
  • Real-time synchronized page navigation and zoom
  • Host-controlled sync mode or free-scroll for peers
  • QR code for instant mobile device pairing
  • Files never touch a server — pure in-memory streaming
