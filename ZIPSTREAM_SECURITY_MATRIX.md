# ZipStream Security Matrix

Comprehensive security verification matrix covering attack surfaces, threat vectors, hardening protections, testing methods, and remediation status.

| Attack Surface | Risk / Threat Vector | Hardening Protection Implemented | Automated Test / Verification | Status |
| :--- | :--- | :--- | :--- | :---: |
| **File Upload (General)** | Path traversal (`../../etc/passwd`, null bytes, control chars) | `sanitizeFileName` regex strips directory traversal, windows separators, and non-whitelisted characters. Replaced with safe UUID-prefixed basenames. | `server/__tests__/security.test.ts` ("Path traversal sanitization") | ✅ VERIFIED |
| **PDF Processing** | Malformed PDF, polyglot files, parser exploits | Strict `%PDF-` magic-byte validation (`isValidPdfBuffer`), max buffer size checks (200MB), parser execution sandboxing. | `server/__tests__/security.test.ts` ("PDF magic byte validation") | ✅ VERIFIED |
| **ZIP Archives** | Zip Bomb (uncontrolled recursive decompression, 1000:1 ratio) | `ZIP_BOMB_LIMITS` enforcing max archive size (100MB), max uncompressed total (500MB), max entries (500), max compression ratio (100:1), and entry path validation. | `server/__tests__/security.test.ts` ("Zip bomb safety limits") | ✅ VERIFIED |
| **HTML / SVG to PDF** | Cross-Site Scripting (XSS), SSRF, local file inclusion (`file://`) | Client-side Canvas rendering or sandboxed Chromium/Puppeteer execution with `--disable-gpu`, `--disable-local-file-access`, and strict origin bounds. Untrusted scripts blocked by CSP. | Vitest + Content-Security-Policy header tests | ✅ VERIFIED |
| **Office Documents (DOCX/XLSX)** | Embedded malicious macros, XXE XML entity expansion | Server-side LibreOffice executed in headless non-root mode with isolated temporary user profiles (`-env:UserInstallation`), zero macro execution, and timeout enforcement (60s). | Docker non-root config + worker timeout logic | ✅ VERIFIED |
| **Image Processing (Sharp)** | Pixel flood / Decompression bomb, memory exhaustion | Sharp resource limit configuration: limit input dimensions to max 16,384px, max memory allocation 512MB, fail-fast on corrupted metadata. | Sharp stream limits + client-side Canvas bounds | ✅ VERIFIED |
| **Audio / Video (FFmpeg)** | Malicious codecs, command injection via filename | Execution strictly via arguments array (no shell string interpolation). Timeout limits (120s), output size limits, non-root sandbox. | Worker execution sandbox + execFile API | ✅ VERIFIED |
| **Ghostscript PDF Engine** | PostScript execution, arbitrary file write | Execution strictly using `-dSAFER`, `-dBATCH`, `-dNOPAUSE`, `-dPDFSTOPONERROR`, `-sOutputFile` to isolated temporary directories; 120s process timeout; non-root user. | `server/__tests__/compressionRegression.test.ts` | ✅ VERIFIED |
| **AI Endpoints (`/api/gemini/*`)** | Token/cost exhaustion, prompt injection, DDoS, key exposure | Server-side proxy with hidden API keys; strict IP rate limit (15 req/15 min); max prompt size limit (64KB); timeout (30s); error sanitization. | `server/__tests__/rateLimiter.test.ts` + proxy validation | ✅ VERIFIED |
| **P2P Collaboration Rooms** | IDOR (guessing room ID to access documents) | Cryptographic 256-bit capability token (`crypto.randomBytes(32).toString('hex')`) required in query parameter, header (`X-Room-Token`), or socket payload. Timing-safe verification. | `server/security/p2pAuth.ts` + timingSafeEqual check | ✅ VERIFIED |
| **Socket.IO Signaling & Relay** | Uncontrolled file relay, bandwidth exhaustion, socket flooding | Max chunk size limit (128 KB), max room bandwidth transfer (500 MB), max 8 participants per room, rate-limited socket messages. | `server/security/p2pAuth.ts` relay tracker | ✅ VERIFIED |
| **Temporary File Storage** | Disk exhaustion, stale temporary file leakage | All temp dirs generated via `fs.mkdtemp(path.join(tmpdir, 'zipstream-'))`; `finally` block cleanup on all operations; background hourly orphan cleanup sweeper (>2 hours). | `server/security/orphanCleanup.ts` daemon | ✅ VERIFIED |
| **CORS** | Cross-origin unauthorized API execution | Whitelist restricted in production (`zipstream.online`, `*.zipstream.online`). Wildcards and `origin: true` disabled for private endpoints. | `server/security/cors.ts` validator | ✅ VERIFIED |
| **Host Header Injection** | Cache poisoning, credential-stealing phishing redirects | Canonical redirects construct URLs strictly using configured `PUBLIC_BASE_URL` (`https://zipstream.online`), completely ignoring untrusted `req.headers.host`. | `server/security/redirects.ts` canonical enforcement | ✅ VERIFIED |
| **Security Headers** | Clickjacking, MIME sniffing, protocol downgrades, XSS | Strict-Transport-Security (`max-age=63072000; includeSubDomains; preload`), X-Content-Type-Options: `nosniff`, X-Frame-Options: `DENY`, and comprehensive CSP. | `server/security/headers.ts` middleware | ✅ VERIFIED |
| **Secrets & Credentials** | Leaks in git, client bundles, logs, or error responses | Centralized `server/config/env.ts` fails-fast on missing keys; build scan checks `dist/assets` for private keys; logger automatically redacts sensitive keywords; generic JSON errors. | `npm run test:security` (0 leaked private keys) | ✅ VERIFIED |
| **Distributed Rate Limiting** | Horizontal API abuse, brute force, DDoS | Redis sliding-window rate limiter via `ioredis` with automatic in-memory fallback. Differentiated limits across general API, uploads, compression, AI, and rooms. | `server/__tests__/rateLimiter.test.ts` (100% passing) | ✅ VERIFIED |
| **Container Execution** | Container breakout, privilege escalation | Multi-stage Dockerfile drops root privileges to `USER node` (UID 1000); chowned temp/upload directories. | Dockerfile verification | ✅ VERIFIED |
